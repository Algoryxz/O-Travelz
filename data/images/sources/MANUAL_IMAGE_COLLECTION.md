# O-TRAVELZ: MANUAL IMAGE COLLECTION CHECKLIST (90 UNRESOLVED PLACES)

> **Authenticity Policy**: Only genuine photographs of the exact place or documented authentic regional Odia dish/experience are accepted. Never use generic stock photos, AI images, PDFs, logos, or photos of other places.

## Collection Workflow
1. Pick an unresolved place from the checklist below.
2. Search using the recommended queries.
3. Save the downloaded image into `data/images/manual/<research_id>.webp` (or `.jpg`/`.png`).
4. Add entry to `data/images/manual/metadata.json` with source URL, license, and verification notes.
5. Run `.venv\Scripts\python.exe scripts/validate_manual_images.py` to confirm validity.

## Source Priority Hierarchy
1. **Tier 1**: Wikimedia Commons / Public Domain (CC0, CC BY, CC BY-SA)
2. **Tier 2**: Official Government / Odisha Tourism / District / ASI Portal
3. **Tier 3**: Official Social Media / Verified Institution Page
4. **Tier 4**: Photographer-owned image with explicit permission
5. **Tier 5**: Personal traveler-supplied photograph
