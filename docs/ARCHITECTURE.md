# Architecture & System Boundaries — O-TRAVELZ

## 1. System Overview

O-TRAVELZ is an intelligent multimodal travel platform built for Odisha. It integrates canonical destination catalogs, verified photographic assets, deterministic transit graph routing (Mo Bus / Ama Bus), live weather, and a grounded AI copilot.

## 2. Core Service Boundaries

### A. Deterministic Services (Canonical Facts)
* **Places & Facilities**: Backed by PostgreSQL (`places`, `place_images`, `services`) with static JSON source of truth (`data/places/places.json`, `data/services/`).
* **Transit Engine**: Deterministic route finding over 154 routes and 1,430 stops (`data/transport/canonical/`). Computes exact schedules, transfers, walking legs, and auto/cab first-mile recommendations.
* **Weather Service**: Fetches live observations from Open-Meteo with honest semantic `unavailable` handling.

### B. AI Copilot (Intent & Explanation)
* **Grounded Boundary**: AI operates strictly on deterministic query results returned by backend tool adapters.
* **Non-Fabrication Guardrail**: AI never invents coordinates, route numbers, schedules, fares, or opening hours.
* **Multi-Tier Execution**: Supports Rule-Based Local Fallback (zero cloud cost), Azure OpenAI, Groq, and Gemini adapters.

---

## 3. Single Source of Truth & Generated Artifacts

1. **Canonical Travel Facts**: Master datasets live in `data/` as version-controlled JSON.
2. **Database Bootstrap**: `scripts/bootstrap_database.py` seeds PostgreSQL from canonical JSON files.
3. **Frontend Offline Fallbacks**: `frontend/src/data/staticTransit*.ts` are deterministically generated by `scripts/generate_frontend_transit_data.py` from canonical transit JSON.

## 4. Shared API Contract Pipeline

Backend Pydantic schemas in `backend/app/schemas/` are the authoritative contract source of truth.

Shared API contracts flow deterministically as follows:

```
FastAPI Pydantic Schemas (backend/app/schemas/)
                     │
                     ▼ (python scripts/generate_openapi.py)
        shared/openapi/openapi.json
                     │
                     ▼ (npm --prefix frontend run generate:api)
          shared/api/generated.ts (Framework-neutral TypeScript)
                     │
       ┌─────────────┴─────────────┐
       ▼                           ▼
Web Client (frontend/)       Mobile Client (mobile/)
```

### Golden Rules
1. **Source of Truth**: FastAPI Pydantic schemas.
2. **Never Hand Edit**: `shared/openapi/openapi.json` and `shared/api/generated.ts`.
3. **Change Lifecycle**: Modify backend schema $\rightarrow$ `python scripts/generate_openapi.py` $\rightarrow$ `npm --prefix frontend run generate:api` $\rightarrow$ compile web/mobile $\rightarrow$ commit together.
4. **Drift Enforcement**: Validated automatically in CI via `python scripts/generate_openapi.py --check` and `python scripts/check_api_drift.py`.
