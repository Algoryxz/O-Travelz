## 2. Architectural Integrity Guardrails

1. **Canonical UUIDv5 Guarantee**: Place identifiers passed to `/itinerary/plan`, `/map/v1/projection`, and saved trips MUST always use deterministic UUIDv5 strings (e.g. `e0f760f3-8f0a-5b12-9c17-91f1a5b81091`), NEVER research strings like `place_013`.
2. **Error Masking Guarantee**: Never display raw Python tracebacks, Pydantic validation errors, or provider details to travelers. All errors must pass through normalized user-friendly Stitch toasts or inline banners.
3. **Zero Backend Modifications**: All existing backend routes (`/places`, `/itinerary/plan`, `/ai/converse`, `/map/v1/projection`, `/weather/current`, `/auth/*`, `/api/v1/sync/*`, `/api/v1/trips/*`) remain untouched.
